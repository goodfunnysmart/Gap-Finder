GAP FINDER (prototype)
======================
Open index.html in any modern browser (double-click). It works offline; the
Lexend font loads from the internet if available, otherwise a system font is used.
Marks are saved in the browser only (localStorage). Nothing is uploaded.

Contents
  index.html           the finished single-file demo
  source/template.html the page code (data placeholder: __DATA__)
  source/build.py      rebuilds index.html from the JSON (python3 build.py, run inside source/)
  source/data/         topics.json and dependencies.json from the Marble Skill Taxonomy
